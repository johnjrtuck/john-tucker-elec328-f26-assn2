# ELEC 328 – Assignment 2: Enchanted VR Flashlight
**John Tucker – S1439352 – jrt15**

A foggy, rainy Victorian back alley at night (Jack the Ripper meets Scooby-Doo) built around the Reality Roost rails. A grabbable flashlight uses a custom Shader Graph to reveal a hidden trail of bloody footprints that leads to a blood sigil and a dagger at the end of the alley.
